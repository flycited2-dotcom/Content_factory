# АРУ — персональные цены и наличие

Правило владельца: весь ассортимент для последующего выбора; в учёте только
«В наличии» с положительной текущей ценой авторизованного аккаунта.
Цена контента = персональная цена × 1,10. Зачёркнутая цена не используется.
Скидки различаются по товарам; опт нельзя считать фиксированной скидкой.
Вход подтверждён в Chrome. Коды, пароли и cookies в файлах не сохраняются.

## Получение снимка

**Исправление от 10.10.2026:** `/vse-tovary/` не покрывает весь ассортимент.
Описанные ниже 8 089 строк и последующее дополнение до 11 638 — исторические
неполные снимки. Рабочий новый сбор обязан проходить всех родителей с
товарами, всех детей и пагинацию всех категорий, а также представления
`/vse-tovary/` и `/novinki/`. Каноническая категория с сегментом `pod-zakaz`
исключается даже при тексте «В наличии». Актуальная процедура:
[ARU_WEEKLY_REFRESH.md](ARU_WEEKLY_REFRESH.md), компилятор
`avito_bridge.ingest.aru_categories`, `completeness_basis=category_tree`.
Приведённая ниже старая команда только для `/vse-tovary/` сохраняется как
история первого этапа, не как рекомендуемый способ полного обновления.

Через авторизованную вкладку https://aru.ooo/vse-tovary/ собираются все
страницы `?page=N` или порции при прокрутке. Каждая порция сохраняется в
отдельный JSON: номер, общее число страниц, признак входа по ссылке «Выйти»,
время, ID, артикул, наличие, текущая цена, ссылка, фото, характеристики.
Цена читается из `.v-products-list__price`, отдельно от `__price-old`.
При сбое продолжать с первой несохранённой страницы; для нового обновления
создавать новую папку, чтобы не смешивать разные снимки.

В репозитории content-factory:

```text
python -m content_factory.ingest.aru_account --pages-dir <папка>/pages --output <папка>/catalog.json
```

Команда отклоняет неполный обход, потерю входа, неверные URL/номера, дубли
ID и данные старше 24 часов. Запись атомарная после проверки. `--preview`
разрешает неполный тест с `complete: false`, который рабочие системы
не используют. В рабочем JSON только товары в наличии с персональной ценой.
Если товар сменил наличие и переместился между страницами во время обхода,
`--reconcile-moved` явно разрешает использовать наблюдение с более поздним
временем; ID и страницы сохраняются в `reconciled_moved_products`. Повтор
ID внутри одной страницы всегда отклоняется. В обходе 09.10.2026 товар
62092 переместился со страницы 134 на 308 и исключён по позднему статусу
«Нет в наличии». Итог: 346 страниц, 10 360 уникальных товаров,
8 089 в наличии с персональной ценой, 2 271 исключён.
Остаток булевый: он не означает известное количество единиц на складе.
Публичный `aru_site` не получает персональные цены; его нельзя запускать
поверх рабочего прайса.

## Использование

Контент-завод: `state/prices/aru-catalog.json`, слот `aru`, `/sources`,
`/find`, `/task`. Наценка по умолчанию +10%, после умножения исходной цены
с копейками результат округляется вверх до целого рубля один раз:
43,48 → 47,828 → 48 ₽. В таблице также есть результат 47,83 ₽.
Явная `/markup aru` меняет наценку контент-завода. Неполный или гостевой
снимок не включается в поиск и задачи. Последний полный прайс не истекает:
он используется до следующего успешного обновления по понедельникам.
Дата прайса видна в `/sources`; задержка обновления не отключает поиск.

Авито: `runtime/aru/catalog.json`, `profiles/aru.yaml`.
`content_markup_pct: 10` задаёт расчёт. Экспорт показывает `account_price`,
`content_price_preview`, артикул и ссылку. Для публикации требуются выбор
ID, `prices_approved: true` и категорийные теги. Публикация в Studio отключена.
Авито показывает дату прайса в строке состояния и подсказке товара.
Возраст снимка не отключает каталог. Фото списка — 180 px; для выбранных
публикаций потребуется получить оригиналы из карточек.

## Будущее обновление

Действующий путь: повторный сбор через авторизованную сессию Chrome и
проверка полного снимка. Если вход истечёт, потребуется обычный вход
с новым кодом владельца. Автономного серверного обновления пока нет.

Владелец подтвердил, что API нет и не будет. Рабочий источник — персональные
цены в Chrome. Еженедельный сбор по понедельникам в 10:00 МСК запускается
в этом чате через автоматизацию Codex. Полная процедура и скрипты:
[ARU_WEEKLY_REFRESH.md](ARU_WEEKLY_REFRESH.md). Последний успешный прайс
сохраняется при истекшем входе, сбое браузера или неполном обходе. Исчезнувшие
из наличия товары удаляются из рабочего каталога после успешного обновления.

Установка сохраняет предыдущие снимки и исходники в резервной копии.
Отчёты и проверочная выгрузка: `../outputs/aru-prices-20261009/`.
Первый гостевой снимок (10 355 товаров, 8 115 в наличии, цены скрыты)
хранится отдельно в `../outputs/aru-20261009/`.
