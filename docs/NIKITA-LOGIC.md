# Никита — логика бота Контент-завода (Telegram, ручная генерация)

Состояние на 2026-09-22, код = прод `/opt/content-factory` (VPS 212.116.115.150).

## Что это
«Никита» — Telegram-бот Контент-завода, сервис `cf-bot` (systemd,
`python -m content_factory.bot.run`, long-poll, один поток). Принимает команды только
от владельца (chat_id из `.env`). Его задача — **ручная** генерация карточек для
Telegram-канала владельца. Автоматический Avito-конвейер — отдельная зона (см. ниже).

## Поток ручной генерации
```
/task (визард) · /find <фраза> + /pick · /make
        │  выбор позиций из прайсов (load_price_slots(..., for_telegram=True))
        ▼
excel_items (state/content_factory.db, status=new)
        │  cf-excel.timer, тик ~10 мин: research (УТП + фото) → карточка
        ▼
очередь фотоагента /root/ritualb2b/queue.db  ──►  дорожки ChatGPT на ПК (desktop/laptop)
        │  готовая карточка
        ▼
превью в review-группу: ✅ Опубликовать · ❌ Отклонить · 🔄 Перегенерировать · 💰 Цена
        │  ответ на превью фото = реальное фото товара (research_cache source=manual)
        ▼
пост в канал
```

## Прайсы
- Папка `state/prices/`. Активные слоты (`ingest/excel_price.py::load_price_slots`):
  `manual__*.xlsx` (загружены владельцем) → `mail__*.xlsx` (почта, по поставщику) →
  legacy `manual/channel/mail.xlsx`. Файлы `archive__*` не читаются.
- **Telegram-фильтр** (2026-09-22): `state/prices/telegram_sources.json`
  `{"disabled": [слоты]}`. `load_price_slots(dir, for_telegram=True)` пропускает
  выключенные ДО разбора. Используют: /task (визард и `top_sections`), /find, /make.
  **Без флага (по умолчанию) — все прайсы**: так читают Avito/витрина
  (`private_price_catalog.py`). Контракт: дефолт `for_telegram=False` не менять.
- Управление: `/sources` → список с номерами, кнопки `🟢 N`/`⚪ N` (callback
  `srctg:N`), тап переключает. Сейчас выключены для Telegram: Бринэкс, instrument.ru.
- Разбор листа: берётся самый полный из трёх парсеров; если в нём нет разделов —
  `_borrow_sections` подтягивает раздел по названию товара из парсера, где разделы есть
  (иначе у БытТехОпт пропадали 130 категорий). Разделы длиннее 70 символов (примечания
  из шапки) в кнопки не попадают.
- Кэш разбора `_PARSE_CACHE` по (mtime, size), выдаются копии позиций (наценка
  `markups.json` меняет цену на месте). Первый разбор ~7 с, далее ~0,02 с.

## Связь с Telegram
С VPS ~30% соединений к api.telegram.org не устанавливаются (IPv4 и IPv6). Клиент бота:
`httpx.Timeout(40, connect=4)` + `HTTPTransport(retries=3)` — иначе однопоточный бот
замирал на 40 с и терял ответ.

## Грабли
- Бот однопоточный: любая медленная операция в обработчике = «тишина» для всех
  команд, а накопившиеся клики потом дают «неожиданное действие для текущего шага».
- Деплой: на VPS нет git. НЕ накатывать `tar src` поверх прода из git/десктопа —
  прод содержит код, которого нет в ветке `master` (VK, Avito, витрина). Правки —
  точечно, с `.bak-ДАТА-метка`, и фиксировать в ветку `server-snapshot-2026-09-22`.
