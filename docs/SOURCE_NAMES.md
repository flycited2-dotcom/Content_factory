# Названия поставщиков в Telegram

Названия задаются в `state/prices/source_names.json` — или в каталоге прайсов,
переданном в приложение. Формат: плоский JSON-словарь, где ключ — точный текущий
слот поставщика, значение — название на кнопке и в меню.

```json
{
  "manual__быттехопт_auto": "БытТехОпт",
  "mail__ma_kobzeva_instrument_ru_прайс_на_5_10_26": "Мир инструмента",
  "splithub": "СплитХаб",
  "aru": "АРУ"
}
```

Пример сохранён в `config/source_names.example.json`. В нём только подтверждённые
слоты. Для нового поставщика добавьте точный ключ его прайса; по похожему имени
файла приложение ничего не угадывает. Ключи, цены, настройки доступности для
Telegram и выбранные товары при переименовании сохраняются.
Почтовый слот «Мир инструмента» проверен на сервере 10.10.2026; если новый
выпуск прайса создаёт новый ключ, добавьте его в JSON отдельно.

Изменения файла читаются при следующем открытии меню, без перезапуска бота.
Отсутствующее или пустое название, отсутствующий файл и некорректный JSON дают
резервное отображение: точный идентификатор слота. Это не скрывает поставщика.
Поддерживаются UTF-8 и UTF-8 с BOM. Пользовательские названия не зашиты в код.

API: `get_source_names(prices_dir) -> dict[str, str]` и
`source_name(prices_dir, slot) -> str` в `content_factory.ingest.source_names`.
Загрузчик только читает файл и не создаёт/не перезаписывает настройки.

На сервер этот код и файл настройки переносятся только после резервной копии и
явного подтверждения владельца. Локальная подготовка не изменяет серверный бот.
