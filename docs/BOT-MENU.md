# Пульт «Никита» — 31.08.2026

`@Sendpr1ce_bot`: `/menu` или `/start` открывает постоянную клавиатуру.
Управление меню доступно только настроенному владельцу в личном чате.
Меню не меняет опросник заказов клиентов, кнопки публикации и старые команды.

- Контент-завод: создание задачи (`/task`), очередь (`/status`), согласование
  (`/pending`), генерация (`/generation`), расписание (`/auto`).
- Avito: кнопка «📦 Avito» в главном меню открывает отдельный раздел. В нём
  доступны статус (`/avito`), первые позиции (`/avito queue`) и группы товаров
  (`/avito categories`). «Категории» открывают страницы с кнопками групп;
  выбор группы показывает её размер и кнопки «Запустить 1/5/10/20» (с учётом
  доступного количества). Только нажатие «Запустить» создаёт партию. Название
  группы, скопированное из списка вместе с числом, тоже открывает этот выбор.
  Статус показывает кнопки общей партии и паузы; текстовая команда
  `/avito start 5 телевизоры` остаётся доступной.
- Прайсы: загрузка существующим обработчиком `.xlsx`, последние обновления
  (`/sources`), поиск товара (`/find`). Загрузка не является командой публикации.
- Парсеры: выбор из существующих служб VPS — остатки I-T-P, гостиницы Крыма,
  климатические заказчики, ритуальный парсер. Запуск выбранного источника
  требует одноразового подтверждения. `systemctl start --no-block` означает
  принятие запроса, а не успешное завершение. systemd не создаёт второй экземпляр
  уже активной службы. Кнопка состояния показывает фактическое состояние службы.
- Система: состояние подключённых служб VPS и их systemd-таймеры.
  Расписание контента отдельно показывает существующую настройку `/auto`.

Пульт тендеров находится в `@S1mfer_bot`; переход есть в главном меню.
`/collect` в «Никите» теперь объясняет, куда перейти, а не возвращает чужую справку.

Раздел и выбранный источник хранятся в `bot_menu` существующей SQLite БД.
Переключение раздела приостанавливает текстовый мастер задачи, не удаляя черновик.
Новый `/task` начинает задачу как раньше. При переключении снимается ожидание
аргумента команды; ответ `/find` обрабатывается до мастера, чтобы не попасть
в старый черновик. Навигация отменяет неиспользованное подтверждение запуска.

Разрешённые службы заданы константами в `bot/control_menu.py`. Telegram-текст
не используется как shell-команда или имя службы. Новые сборщики подключаются
после проверки их реального способа запуска. Меню не управляет службами Windows.

# Повторный выбор после отмены (02.10.2026)

В «Контент-заводе» кнопка «📋 Очередь» открывает `/excel`, где последняя выбранная партия показывается отдельно от всей истории. Список содержит названия товаров, состояния и фактически принятое количество. «Отменить последнюю партию» сохраняет другие задания; «Отменить всю очередь» действует на весь незавершённый хвост, включая расписание и неподтверждённую отправку.

После подтверждения задачи «Сейчас» бот запрашивает немедленный запуск
обработчика. Резервный таймер проверяет очередь каждую минуту. Ответ
«Запуск конвейера запрошен» означает принятие команды запуска; фактическое
начало видно в `/excel`. Статус показывает «ждёт дорожку (A1/A2)»,
«в работе (A1/A2)», готовые превью и ошибку последнего запуска.

Отменённые товары можно заново выбрать через `/task`, `/find` + `/pick` или `/make`. Бот возобновляет только явно выбранные товары и сохраняет готовые результаты. Выполняющиеся и невыясненные запросы не дублируются. `/generation on` разрешает новые задания, но не оживляет отменённый хвост.

Таймаут при отправке своего фото не запускает обычный поиск другого фото. Состояние отправки проверяется по сохранённому идентификатору запроса в очереди фотоагента. Отмена сохраняется даже при позднем ответе API. Новые журналы действий хранятся в `bot_task_events`, состав партий — в `excel_selections`.
