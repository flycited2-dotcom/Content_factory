# АРУ — подключение каталога, 09.10.2026

Ниже — журнал первого подключения открытого каталога. Актуальные правила
персональных цен, наличия и наценки +10%: [ARU_ACCOUNT_PRICES.md](ARU_ACCOUNT_PRICES.md).

**Устаревший этап, исправлено 10.10.2026:** представление `/vse-tovary/`
не является всем ассортиментом; старые количества не доказывают полноту.
Указанный ниже срок 24 часа больше не действует для установленного прайса.
Рабочая процедура с полным деревом категорий и исключением под заказ:
[ARU_WEEKLY_REFRESH.md](ARU_WEEKLY_REFRESH.md). Этот файл — исторический журнал.

Владелец выбрал весь каталог https://aru.ooo/ с последующим ручным выбором
товаров для публикации. Использовать персональные цены кабинета; наценка пока
не определена. Публикация и платная генерация не запускались.

`content_factory.ingest.aru_site` читает все страницы `/vse-tovary/` и сохраняет
полный JSON атомарно только после успешного обхода. Фиксируются ID товара,
артикул, бренд, название, ссылка, фото, доступные характеристики, описание,
признак наличия и цена, если сайт её показывает. Признак «В наличии» не означает
известное количество. Скрытая цена сохраняется как null, без подстановки нуля.
Фотографии списка могут иметь низкое разрешение; до генерации необходимо
получить оригинал из карточки выбранного товара.

Снимок для контент-завода: `state/prices/aru-catalog.json`. Команда `/sources`
показывает АРУ отдельно от действующих прайсов. Пока персональный прайс не
получен, АРУ не участвует в `/find`, `/task` и платной генерации.

Снимок Авито: `runtime/aru/catalog.json`. Профиль `profiles/aru.yaml` и селектор
АРУ в Avito Studio позволяют просматривать весь каталог. Профиль Studio
отключает публикацию; адаптер также не устанавливает цену продажи до
`prices_approved: true`, выбора ID товара и назначения его категорийных тегов.
ID объявления привязан к стабильному ID товара сайта, а не к его названию.
Снимок старше 24 часов отклоняется.

Получение открытого каталога на сервере:

```text
/opt/avito-bridge/.venv/bin/python /opt/content-factory/src/content_factory/ingest/aru_site.py --output /opt/avito-bridge/runtime/aru/catalog.json
```

Цены открытого каталога скрыты. Авторизация существующего аккаунта через
одноразовый код дошла до отправки кода, но форма осталась с заблокированной
кнопкой и индикатором загрузки. Успешный вход не подтверждён. Код, email и
сессионные данные в исходниках не сохраняются.

Остаётся получить доступ к кабинету и способ обновления персонального прайса,
согласовать наценку, выбрать товары и проверить категории/оригинальные фото.
Автообновление через таймер на этом этапе не устанавливается.

Результат первой полной загрузки: 10 355 товаров на 346 страницах; 8 115
помечены сайтом «В наличии», 2 240 — «Нет в наличии». Все товары содержат фото,
цены скрыты у всех. Снимки установлены в обе системы, `/sources` и серверный
экспорт каталога Авито проверены. Бот контент-завода активен. Исправлена
ошибка `/sources` при отображении виртуального каталога SplitHub без XLSX.
