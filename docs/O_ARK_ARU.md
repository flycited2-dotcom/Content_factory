## Правила владельца

- Весь доступный ассортимент, без общего ограничения товаров/групп.
- Только точное «В наличии» и положительная текущая персональная цена.
- «Нет в наличии», неизвестное наличие и под заказ исключаются.
- Канонический URL с отдельным сегментом `pod-zakaz` исключается даже при
  ошибочной надписи карточки «В наличии»; без blacklist ID и догадок по имени.
- Цена контента: `ceil(Decimal(price) * Decimal('1.10'))` в целых рублях
  **один раз**. Зачёркнутую цену не использовать. Пример 43.48→47.828→48₽.
- API нет и не будет. Обновление через выбранный авторизованный браузер по понедельникам 10:00 МСК.
- Последний успешный полный прайс действует до следующей успешной замены.
  При сбое он сохраняется, дата не подменяется временем копирования.
- **24 часа — свежесть/максимальный разброс исходных страниц нового прохода,
  а не TTL установленного прайса.** Неделя ожидания не отключает каталог.
- Наличие булево, на дату наблюдения. `stock=1` не означает известный
  остаток одной штуки. Подключение базы не разрешает публикацию всего каталога.
- Новый `/task` начинается с поставщика, затем открывает только его русское
  дерево разделов. Категории других поставщиков не смешиваются в этом выборе.
- На странице меню ровно до 10 категорий; все следующие страницы доступны.
  Для партии нужны кнопка «Своё число», первые N товаров и номера/диапазоны.
- Следующие изменения рабочего сервера требуют **отдельного явного
  подтверждения владельца и резервной копии перед установкой**. Подготовка
  локального кода, отчёта или Git review сама по себе не разрешает deploy.

## Контракт JSON с проверяемым покрытием

Сохраняется `schema_version=1`. Заголовок рабочего снимка:

```text
source="aru", complete=true, authenticated=true, price_basis="account_price"
completeness_basis="category_tree"
generated_at=ISO8601 с timezone, самое раннее наблюдение нового прохода
pages=captured_pages=сумма сохранённых страниц всех узлов
scanned_products=уникальные ID до фильтра
excluded_products=исключённые уникальные ID
excluded_by_reason={on_order_category, not_in_stock, unpriced}
categories=[{id,name,parent_id,url,path_ids,path_names}, ...]
category_scan={required_categories,captured_categories,observations,
               unique_products,duplicates_reconciled,missing_categories:[],
               categories:[{id,pages,captured_pages,observations}, ...]}
items=[...товары, прошедшие фильтр...]
```

Проверка `validate_category_coverage` из
`avito_bridge.ingest.aru_categories` требует совпадения всех узлов и
страниц 1..N каждого узла, согласованности статистики и taxonomy. Ни 346,
ни 8 089/11 638 не являются постоянными контрольными числами.

Товар: строковый `id`, `article`, `name`, `brand`, канонический `url`,
`available=true`, `stock_text="В наличии"`, положительная Decimal-строка
`price`, `price_basis="account_price"`, `captured_at`, изображения,
характеристики и описание. `content_price` — контрольный результат+10%
с копейками; `content_price_rub` — готовая целая цена с округлением вверх.

**Иерархия в строке:** `category_path` — массив русских отображаемых названий,
`category_ids` — массив стабильных URL-prefix ID с начальным/конечным `/`.
`category_slugs` — исходные сегменты, для проверки, не подписи интерфейса.

```json
{
  "category_path": ["Электроинструмент", "Генераторы"],
  "category_ids": ["/elektroinstrument/", "/elektroinstrument/generatory/"],
  "category_slugs": ["elektroinstrument", "generatory"]
}
```

У дочерней категории `parent_id="/elektroinstrument/"`. Не склеивать
одинаковые названия подгрупп в разных ветках, не обрезать пути 70 символами.
Использовать каноническую категорию товара, а не страницу представления,
на которой он встретился. `/vse-tovary/` может называться «Прочие товары»
в валидированной taxonomy, если это реальная каноническая категория.

## Telegram: подключение и исправленная навигация

Предпочтительная точка подключения — существующий слот `aru`:

```python
from pathlib import Path
from content_factory.ingest.excel_price import load_price_slots

slots = load_price_slots(Path('/opt/content-factory/state/prices'), for_telegram=True)
aru_items = next((items for label, items in slots if label == 'aru'), [])
```

`PriceItem.price` уже содержит +10% и целое округление. `PriceItem` дополнен
`category_path`, `category_ids`; `section` содержит русский полный путь.
Загрузчик использует taxonomy для подписей. `merge_supplement` сохранён,
но не заменяет доказательство нового полного `category_tree`-прохода.

Новая последовательность `/task`:

**Поставщик → корневой раздел → подгруппа → товары → выбранная партия →
время → предпросмотр/подтверждение.** Даже единственный доступный поставщик
не отменяет первый шаг. Текст категории до выбора поставщика возвращает
меню поставщиков. После выбора поиск и дерево используют только этот слот.

`bot/catalog_tree.py`, `bot/wizard.py`, `bot/wizard_flow.py` обеспечивают:

- Поставщик с количеством доступных товаров → корень → подгруппы → точные
  товары; также все товары выбранной ветки. Поставщики листаются отдельно.
- До **10 категорий на странице**, полная пагинация каждого уровня.
- Полный список, 20 на странице, дальнейшие страницы без общего лимита 30.
- Чекбоксы, выбор/снятие страницы, снятие всего, отдельное продолжение.
- Кнопка «✏️ Своё число»: отдельный запрос целого N от 1 до размера списка,
  затем первые N позиций в текущем порядке. Дроби, ноль и превышение числа
  товаров отклоняются без сокращения списка и без постановки в очередь.
- Выбор по номерам и диапазонам, например `3 14 32, 10-15`; номера начинаются
  с 1, пересечения удаляются. Неверный номер или обратный диапазон требует
  исправления ввода, а не молча уменьшает партию.
- Сохранение `source_slot`, страницы, выбранных ключей и шага запроса N в
  SQLite при листании/рестарте. Миграция старой таблицы сохраняет черновики.
- Защиту кнопок старого списка и другого поставщика; краткий bulk-отчёт при
  полной очереди. Отображаемое имя не определяет идентификатор поставщика.

### Редактируемые названия поставщиков

`state/prices/source_names.json` в **фактическом** каталоге прайсов агента —
плоский JSON-словарь точный slot → русское отображаемое название. Имена не
зашиты в runtime-код и не угадываются по похожему имени файла.
`content_factory.ingest.source_names` предоставляет:

```python
get_source_names(prices_dir)  # dict[str, str]
source_name(prices_dir, slot) # имя из JSON либо точный исходный slot
```

Файл перечитывается на каждом вызове, поэтому после редактирования новые
имена появляются при следующем открытии меню без перезапуска. UTF-8 и BOM
поддерживаются; отсутствие файла, пустое имя или некорректный JSON дают
точный slot и не скрывают поставщика. Переименование не меняет цены,
доступность для Telegram, anti-duplicate keys или выбранные товары.

Редактируемый пример: `config/source_names.example.json`; инструкция:
`docs/SOURCE_NAMES.md` в Content Factory. Подтверждённые слоты примера:

| Slot | Предлагаемая подпись в JSON |
|---|---|
| `manual__быттехопт_auto` | БытТехОпт |
| `mail__ma_kobzeva_instrument_ru_прайс_на_5_10_26` | Мир инструмента |
| `splithub` | СплитХаб |
| `aru` | АРУ |

Почтовый slot instrument.ru подтверждён read-only аудитом 10.10.2026.
При новом датированном ключе прайса требуется новая запись в JSON.
Пример не устанавливается в рабочую state-папку автоматически. На момент
аудита серверный `source_names.json` отсутствовал; рабочие имена после
развёртывания нужно проверить отдельно, а не считать уже установленными.

Видимые группы в Telegram и Avito должны быть на русском по названиям
поставщика: например «Электроинструмент» → «Перфораторы» → товары.

Фирменные названия вроде DCK/CHAMPION сохраняются как бренды, не переводятся
в выдуманные названия. Старый снимок со slug-путями должен быть заменён

## Приёмка готового подключения

1. Новый JSON проходит `validate_category_coverage`; количества сверены с
   новым отчётом, а не историческими снимками.
2. Доступны Электроинструмент→подгруппы→товары, в том числе последний товар
   группы после листания; нет общего усечения первых 30.
3. `/task` сначала предлагает поставщика с именем из `source_names.json` и
   количеством. Дальнейший поиск/дерево принадлежат только ему; старые
   кнопки другого поставщика отклоняются. Имена меняются без перезапуска.
4. Категории листаются по 10 на каждом уровне. «Своё число» выбирает первые
   N из полного текущего списка; номера/диапазоны работают после 30-й
   позиции. Недопустимый ввод не вызывает генерацию/очередь.
5. Выбор переживает страницы/рестарт; bulk меняет явно выбранную область,
   снятие всего работает. Под заказ/отсутствующих/неоценённых строк нет.
6. Цена account+10% начислена один раз; дата не меняется от копирования.
7. Старый успешный прайс остаётся при сбое. Новый пост/объявление проходит
   существующее подтверждение, повтор не создаёт публикационный дубль.
8. Перед рабочим deploy получены отдельное явное подтверждение владельца
   и резервная копия. Проверка локального кода не отмечается как установка.
